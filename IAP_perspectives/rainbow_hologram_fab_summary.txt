-- NOTES / CAVEATS --
- A generic sanity floor of MIN_LINE_WIDTH_UM = 0.2 um is already
  applied: any pixel whose line width would fall below that is skipped, so the
  min line width above should never be absurdly thin (e.g. sub-nanometer). This
  is a generic floor, not your chosen process's real resolution -- once a process
  is picked, tighten it to match (e.g. ~1.5 um for the DMD/UV tool discussed).
- Sign convention: d*(sin(alpha)+sin(beta)) = lambda, alpha and beta on
  the same side of the substrate normal. Verify against the real
  illumination/observation geometry before fabrication.
- These ranges are the true (non-quantized) physical values from the
  design. A downstream GDS-generation step may quantize duty cycle to a
  handful of discrete levels to keep the file small, but the equipment
  still needs to resolve the min/max feature widths listed above.
- Curvature correction (R/G/B blur) and proximity-effect dose correction
  are not applied at this stage.
